# 第二题　思考题回答

## 16. 模型能力从哪里来？

模型的能力来自**网络结构与数据/任务的匹配程度**，可以拆成三层来看：

**1）结构决定假设空间（能不能表达）**
线性模型的结构限定了它只能表达 `y = XW + b`。而 `make_friedman1` 的真实函数里包含 `sin(π·x1·x2)`（交互项）和 `20(x3-0.5)²`（二次项），这些**不在线性模型的假设空间里**，所以无论怎么训练，测试 RMSE 都停在较大值，训练 MSE 曲线 几轮后就贴平在 0.28。MLP 加入 ReLU 之后，多层复合可以逼近这些项，测试 RMSE 直接降到 1.36，R² 从 0.77 提到 0.92。同一个任务、同一份数据、同一个优化器，只改结构，能力就变了。

**2）容量决定上限，数据与正则决定能不能达到上限**
MLP 的参数量是线性模型的约 256 倍，训练集 RMSE（0.71）远优于线性模型（2.57）；但它的验证 MSE（0.0699）明显高于训练 MSE（0.0082），说明容量已经开始"溢出"到记住训练集的噪声，需要早停或正则来约束。也就是说：结构给出"能做到多好"的可能，数据和训练方式决定这种可能被实现多少。

**3）优化器与训练过程决定能不能走到那里**
同样的结构，如果学习率过大或过小，也达不到这个 RMSE。此外本实验对输入和标签都做了标准化，这也是让梯度下降能顺利收敛的工程条件。

一句话：能力 = 结构提供的表达能力 × 数据提供的信息量 × 训练能否有效优化，三者缺一指标就上不去。

## 2. "更深"一定意味着"更强"吗？

**不一定。而且在图示情况下这个设定下，一定是"不更强"——多层等于一层。**

数学上可以直接合并：

```
h1 = W1·x + b1
h2 = W2·h1 + b2
...
y  = Wk·h(k-1) + bk
```

把 h1、h2 一层层代进去，所有矩阵相乘仍然是**一个矩阵**：

```
y = (Wk·...·W1)·x + b'   →  等价于一层线性变换
```

所以：

- 它的假设空间与单层 `nn.Linear` **完全相同**，参数再多也只是同一个函数的冗余参数化，表达能力的**上界没变**；
- 因此它拟合不了 XOR、`sin(π·x1·x2)` 这类非线性关系，测试误差会与单层线性模型基本一致（甚至因为更难优化/更容易过拟合而更差）；
- **只有插入非线性激活函数（ReLU/Tanh/GELU），层与层之间才有了"折叠空间"的能力**，深度才真正带来表达能力的增长。

实验佐证：在延伸思考 1 里，激活函数存在时，1 层窄网络 [32] 的测试 RMSE 是 1.2992、3 层 [128,64,32] 是 1.3544、2 层宽网络 [256,256] 是 1.3019——**三者几乎相同层多甚至更差**，说明在本题这个数据规模和噪声水平（noise=1.0）下，加深加宽并没有带来实质提升。可见"深/大"本身不等于"强"，是否更强取决于数据是否需要那么复杂的函数。

## 3. 模型越复杂越好吗？

**不是。** 结合本次实验的现象：

**1）从线性到 MLP（结构从"不够"到"够"）**
测试 RMSE 2.3185 → 1.3624，R² 0.7694 → 0.9204。这一步是补上缺失的表达能力，复杂度换来了明显收益。

**2）继续在 MLP 内部加宽加深（延伸思考 1）**
参数量从 385（1 层 32 个神经元）一路加到 68865（2 层 256×256），测试 RMSE 却只在 1.2992 ~ 1.3843 之间波动，表现最好的反而是**最小的** [32] 网络，最大的 [256,256] 并没有更好。同时训练集 RMSE 越来越小（0.9019 → 0.7626），说明多出来的参数主要在**拟合噪声**，而不是学规律。

**3）为什么**
训练样本只有 900 条，标签上还带着 noise=1.0 的高斯噪声，函数复杂度的"真实需求"已经被数据的信息量限制住了。此时增加容量：训练误差继续降（能记住噪声），测试误差不再降甚至上升 → 进入过拟合区。

**4）噪声越大，复杂度的收益越小（延伸思考 2）**
noise=0.0 时 MLP 比线性模型好 1.73（RMSE 0.43 vs 2.16）；noise=4.0 时两者几乎一样（4.4147 vs 4.4882，只差 0.07）。当数据本身的随机性占主导时，再复杂的模型也无法突破噪声下限。

**结论**：模型复杂度应该与"任务的真实复杂度 + 数据量 + 噪声水平"相匹配。合适的做法是：先用简单模型做基线，再逐步增加容量，用**验证集**（不是训练集）判断是否真的有收益，并配合正则化/早停/数据增强。盲目堆参数只会增加成本并带来过拟合。
