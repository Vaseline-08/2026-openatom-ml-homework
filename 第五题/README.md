# 大模型 API 调用初体验 —— 校园信息助手（第 5 题：任务一 / 任务二 / 任务三）

本项目完成了机器学习招新题第 5 题：通过 Python 调用云端大模型 API，实现一次简单对话（任务一）、一个按下述固定格式输出的命令行"校园信息助手"（任务二），并用两种提示词做了对照实验（任务三）。

## 一、所用平台与模型

- 平台：DeepSeek 开放平台
- 模型：`deepseek-chat`
- 接口类型：OpenAI 兼容接口，`base_url = https://api.deepseek.com`
- 实测运行环境：Python 3.10.21（Anaconda 环境：`D:\A\envs\pytorch`），`openai 3.29.0`、`python-dotenv`

## 二、环境要求

- Python 3.10 及以上（本项目在 3.10.21 上实测通过）
- 使用 Anaconda 创建的虚拟环境
- 依赖包：`openai`、`python-dotenv`（见 `requirements.txt`）

## 三、安装依赖

在 PyCharm 底部的 Terminal 中运行：

```bash
pip install -r requirements.txt
```

如果下载速度较慢，可以使用清华源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 四、API Key 配置

1. 复制项目中的 `.env.example` 文件，重命名为 `.env`。
2. 在 `.env` 文件中填入你自己的 API Key（变量名必须与代码一致）：

```
DEEPSEEK_API_KEY=你的真实key
```

3. 注意：`.env` 文件已被写入 `.gitignore`，**请勿将其上传到 GitHub**；提交时只提交 `.env.example`（其中不含真实 Key）。

## 五、运行方法

| 对应任务 | 运行命令 | 说明 |
|---|---|---|
| 任务二（完整提示词版） | `python main.py` | 交互式"校园信息助手"，输出固定三行格式 |
| 任务三（简单提示词版） | `python text_prompt.py` | 与 `main.py` 唯一差别是系统提示词只有"总结以下通知"，用于对照 |

- 在 PyCharm 中也可以直接右键运行对应脚本；两个脚本的**代码逻辑完全相同，只改了 `SYSTEM_PROMPT`**，这样两次输出才有可比性。

## 六、程序功能说明（任务二）

`main.py` 的系统提示词规定了**角色、输出格式和约束条件**：

1. **角色**：你是一个校园信息助手。
2. **固定输出格式**（模型必须严格按此三行输出，不加额外说明）：

```
一句话总结：
关键信息：
待办事项：
```

3. **约束条件**：
   - 只依据用户提供的文本，不编造原文中没有的信息；
   - 原文没有时间、地点或截止日期时，在对应位置写"未提及"；
   - 原文没有明确任务时，待办事项写"无明确待办"。

程序结构：`load_dotenv()` 从 `.env` 读取 Key（读不到时主动抛错提示）→ 构造 OpenAI 兼容客户端 → 循环读取用户输入并调用 `deepseek-chat`（`temperature=0.3`，`stream=False`）→ 打印模型回答；调用异常时捕获并打印错误信息，不会让程序崩溃。
