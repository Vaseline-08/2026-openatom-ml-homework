# 一、理论问答

## 1. 卷积层是什么？在 CNN 中有什么作用？

**是什么**：卷积层由一组可学习的**卷积核（filter/kernel）**组成。卷积核在输入特征图上按设定步长滑动，在每个位置上做**局部加权求和**（逐元素相乘再相加，加上偏置），得到一个输出值；所有位置的结果拼成一张输出特征图。若输出通道数为 $C_{out}$，就有 $C_{out}$ 组卷积核。

**在 CNN 中的作用**：
1. **提取局部特征**：浅层卷积学边缘、颜色、角点、纹理；中层组合成部件（圆环、三角形边框、数字笔画）；深层组合成完整语义（"红色圆形限速标志"）。
2. **权值共享 → 参数量极少**：一个 3×3 卷积核只有 9×C 个参数，却要在整张图上复用；而全连接层每个位置都要一套独立权重。
3. **平移等变**：同一特征出现在图像的任何位置，都能被同一个卷积核检测到（响应位置跟着平移）。
4. **保留空间结构**：输出仍是二维特征图，保留了"谁挨着谁"的邻域关系，供后续层继续利用。
5. **逐级扩大感受野、逐级抽象**：多层堆叠后，越深的神经元看到的原图区域越大、语义越抽象。

## 2. 卷积层与全连接层相比，处理图像时有哪些优势？

| 维度 | 全连接层 | 卷积层 |
|---|---|---|
| 参数数量 | 32×32×3 = 3072 个输入，若第一层 128 个神经元就要 3072×128 ≈ 39 万参数 | 32 个 3×3×3 卷积核只有 864 个参数 |
| 连接方式 | 每个输入像素与每个神经元全连接 | 局部连接（只看邻域），权值共享 |
| 空间结构 | 展平后丢失邻域关系 | 保留二维结构 |
| 平移鲁棒性 | 无（图像整体平移，输入向量完全变化） | 有（卷积天然平移等变） |
| 过拟合风险 | 高（参数太多） | 低（参数少 + 共享带来的强正则） |

所以处理图像时，卷积层用**远更少的参数**获得了**更强的先验（局部性 + 平移等变）**，训练更快、更省显存、泛化更好。全连接层通常只放在网络末端做分类决策，或者在特征图已经很小（如 4×4×128）时使用。

## 3. 卷积核越大，模型一定越好吗？为什么很多 CNN 更喜欢连续使用多个较小的卷积核，而不是直接使用一个很大的卷积核？

**不一定更好**。卷积核越大：
- 感受野确实更大（一次就看到更大范围），但**参数与计算量按 $K^2$ 增长**（5×5 是 3×3 的约 2.8 倍）；
- 对**局部细节的刻画变粗**，小目标、细笔画（比如限速牌里的数字）容易被平均掉；
- 更容易过拟合（参数多），且梯度传播路径上的非线性更少。

**连续使用多个小卷积核更好**，理由是（以两层 3×3 代替一层 5×5 为例）：
1. **感受野相同**：两层 3×3 的有效感受野 = 5×5；
2. **参数更少**：$2\times3^2=18 < 5^2=25$（通道数相同时）；
3. **非线性更强**：中间多了一次 ReLU，表达能力比单一线性卷积更强；
4. **正则效果**：参数少、层级多，等效于对小核做了更强的约束，训练更稳；
5. **计算效率与硬件友好**：3×3 小核更易并行、更省显存（这是 VGG 的核心结论，之后几乎成为默认设计）。

> 例外：某些任务确实需要大感受野（如大目标检测、空洞卷积替代大核），这时会用**空洞卷积（dilated conv）**或**全局注意力**来以更低代价获得大范围上下文。

## 4. Pooling 有什么作用？Max Pooling 和 Average Pooling 分别做了什么？

**作用**：
1. **降采样**：把特征图尺寸减半，减少后续计算量与显存；
2. **扩大感受野**：后续层同样大小的卷积核能看到更大范围的原图；
3. **保留主要信息、抑制次要细节**：对小幅平移/形变不那么敏感（带来一定的平移不变性）；
4. **抑制过拟合**：特征图变小 → 后面全连接层参数变少。

**区别**：
- **Max Pooling**：取窗口内**最大值**，即"这个区域里最强的响应"。它保留最显著的证据（边缘、纹理、显著部件），对局部纹理变化更鲁棒，**CNN 中最常用**（你第三题的模型也是 `nn.MaxPool2d(2, 2)`）。
- **Average Pooling**：取窗口内**平均值**，保留区域内的整体强度信息，结果更平滑。常用于网络末端（如 **全局平均池化** 替代全连接层）或对整体亮度/密度敏感的任务。
- 极端的 Max Pooling 会丢弃"有多少个响应"的信息，Average Pooling 会把弱响应也平均进来；实际取舍取决于任务更看重"最强证据"还是"平均强度"。
- 注意：池化**不改变通道数**，也不是必须的——有些现代网络用**步长卷积**代替池化来做降采样。

## 5. 什么是感受野？

**定义**：输出特征图（或某个神经元）上的一个像素，**反向对应到原始输入图像上、能够影响这个像素值的区域大小**，就叫感受野。

**怎么算**：逐层累加。第 $l$ 层感受野
$$RF_l = RF_{l-1} + (K_l - 1)\times \prod_{i<l} S_i$$
即每加一层卷积核大小为 $K$ 的层，感受野增加 $(K-1)\times$（之前所有层的步长乘积）。

**为什么重要**：
- 感受野太小 → 神经元只能看到局部细节，无法判断"这是个整体标志还是标志的一部分"，语义判断容易错；
- 感受野太大 → 可能把不相关的背景也卷进来，且参数/计算成本高；
- 设计网络时要让**最后一层的感受野 ≥ 目标物体的典型尺度**。你第三题的网络（3 次 3×3 卷积 + 3 次 2×2 池化）最终感受野已经覆盖 32×32 的整张输入，所以能对整幅标志做判断。

## 6. 卷积层输出尺寸的计算公式 + 计算题

**公式**（$H_{in}$ 输入高，$P$ 填充，$K$ 卷积核，$S$ 步长）：
$$H_{out}=\left\lfloor\frac{H_{in}+2P-K}{S}\right\rfloor+1$$

**题目**：输入 **32×32×3**；第一层卷积 $K=5$、$S=1$、$P=2$、输出通道 **16**；第二层最大池化 $K=2$、$S=2$、无填充。

**a. 经过第一层卷积后**
$$H_{out}=\frac{32+2\times2-5}{1}+1=32$$
→ 输出尺寸 **32 × 32 × 16**
（宽高不变是因为 $P=2$ 恰好补齐了 $K=5$ 带来的尺寸损失：$2P=K-1$；通道数由卷积核个数决定，从 3 变成 16）

**b. 再经过最大池化后**
$$H_{out}=\frac{32-2}{2}+1=16$$
→ 输出尺寸 **16 × 16 × 16**
（池化不改变通道数，16 个通道保持不变）

**补充**：如果在这里接一个全连接层，输入维度就是 $16\times16\times16=4096$；你第三题的网络结构是三次"卷积+池化"，$32\to16\to8\to4$，所以 `fc1` 的输入是 $128\times4\times4=2048$，与你自己代码里写的 `128*4*4` 完全对应。
