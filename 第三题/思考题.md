# 第三题　思考题回答

## 1. 为什么模型在原始测试集上准确率很高，但经过轻微的亮度变化、模糊或旋转后，性能可能明显下降？

> 结合你自己的实验数据：原始 **89.75%**，低亮度(×0.6) **87.59%**，高亮度(×1.3) **88.21%**，模糊(σ=0.8) **87.97%**，噪声(std=0.03) **88.04%**。下降最大的是**低亮度（-2.17）**，其次是**模糊（-1.78）**。

1. **分布偏移（distribution shift）**：原始测试集与训练集同分布；一旦加扰动，测试样本就落到了训练分布之外（OOD），模型的决策边界不再适用。
2. **CNN 依赖的低层特征最脆弱**：亮度/模糊/旋转首先破坏的是**边缘、对比度、颜色、纹理**这些浅层特征。而浅层特征又是深层语义的基础，误差会逐层累积。
3. **"捷径特征"被破坏**：训练时模型可以偷懒地依赖与光照/清晰度相关的线索（例如"数字笔画很锐利 = 限速牌"）。扰动恰好让这些线索失效。
4. **细分任务对细节最敏感**：GTSRB 有 43 类，其中一大堆是限速牌（30/50/60/80…），**唯一区别就是圆环中的数字**。变暗或模糊后数字笔画最先糊掉，类间距离急剧缩小，所以错误集中出现。
5. **普通卷积不含旋转/尺度/亮度不变性**：CNN 只有**平移**等变性，旋转变化较大时（例如 15° 以上）卷积核的响应会发生明显变化；我在扰动实验里只用了**小角度**旋转，正是因为这个原因。
6. **BatchNorm 帮不上忙**：BN 用的是训练时的 running 统计量，输入整体变暗相当于激活分布整体平移，固定的统计量无法自适应；反之，**在输入侧做标准化**（固定 mean/std）能部分缓解——这正是改进方案里加 `Normalize` 的理由。

## 2. 数据增强的作用有哪些？它实际上会对模型学习到的特征产生什么影响？

**作用**：
1. **扩充有效数据**：用几何/光度变换从有限样本中造出"合理但不同"的新样本；
2. **注入不变性先验**：旋转/平移/缩放/亮度抖动 = 告诉模型"这些变化不改变类别"；
3. **正则化、抑制过拟合**：模型无法记忆固定像素模式，训练误差上升但泛化误差下降；
4. **提升对分布偏移的鲁棒性**：本题目中就是对亮度/模糊/旋转类扰动的抵抗能力；
5. **缓解类别不平衡**：可对少数类做更强增强。

**对模型学到特征的影响（机理）**：
1. **从"记纹理"转向"学形状/结构"**：当同类样本的亮度、角度、位置每次都不同，任何依赖固定亮度或固定像素位置的捷径都会失效，模型只能抓更本质的轮廓与部件；
2. **特征空间更平滑、类内更紧凑**：同类样本经不同增强后仍要被映射到同一类，等价于对类内样本做平滑插值，决策边界不再贴着个别样本；
3. **降低对高频细节的依赖**：模糊/噪声类增强让模型不迷信像素级细节，转而依赖低频结构 → 在模糊扰动下更稳；
4. **代价与边界**：
   - 增强必须**语义合理**：交通标志做水平翻转会把"靠右行驶"之类图案翻转成另一类语义，相当于注入错误标签，**所以我这题没有用翻转**；
   - 增强强度过大会让训练分布偏离真实测试分布，导致原始测试集准确率下降；
   - 增强**不能凭空创造训练集中完全不存在的信息**（例如训练集全是白天照片，增强出不来真正的夜间图像）——这种情况要靠采集数据或域适应。
