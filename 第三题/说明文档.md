## 五、实验摘要

### 5.1 基础模型

- **模型**：3 组「Conv3×3 + ReLU + MaxPool2×2」，通道 3 → 32 → 64 → 128，特征图 32 → 16 → 8 → 4；展平后 `Linear(2048→128) + ReLU + Dropout(0.5) + Linear(128→43)`
- **训练**：CrossEntropyLoss + Adam(lr=1e-3)，batch_size=64，10 个 epoch
- **结果**：原始测试集准确率 **89.75%**（Loss 从 1.3890 降到 0.2008）

### 5.2 鲁棒性测试（4 种扰动）

| 测试条件 | 准确率 | 相对原始下降 |
|---|---|---|
| 原始测试集 | 89.75% | 0.00 |
| 低亮度（×0.6） | 87.59% | **-2.17** |
| 高亮度（×1.3） | 88.21% | -1.54 |
| 图像模糊（σ=0.8） | 87.97% | -1.78 |
| 高斯噪声（std=0.03） | 88.04% | -1.72 |

下降最明显的是**低亮度**，其次是图像模糊——这两类扰动恰好打在 CNN 最依赖的低层特征（边缘、对比度）上。

### 5.3 改进实验（A/B/C 三组对照）

针对亮度与模糊设计改进：训练时加数据增强（小角度旋转、平移缩放、亮度对比度抖动）+ 用训练集统计量做输入标准化。保持网络结构、batch、优化器、lr、epoch、种子一致，只改数据管线：

| 组别 | 训练预处理 | 原始测试集准确率 |
|---|---|---|
| A 基准 | `Resize + ToTensor` | 91.53% |
| B 改进① | `+ 数据增强` | 88.63% |
| C 改进② | `+ 数据增强 + 标准化` | **91.70%** |

C 组原始准确率最高（相对 A 组 +0.17 个百分点），低亮度的下降幅度从 3.48 收到 **1.09**；B 组原始准确率下降，且模糊/噪声更差；C 组在模糊/噪声上也变差。详细数据表、原因讨论和下一步计划见 `思考题.md` 的"附二"。

## 六、学习笔记

### 6.1 我这次实验做了什么

1. **数据**：`torchvision.datasets.GTSRB`，训练集 26640 张、测试集 12630 张、43 类；数据放在本机 `E:/CV_Data`，用 `download=False` 直接读（不联网）。统一 `Resize((32,32))` + `ToTensor()`。
2. **模型**：`TrafficSignCNN` —— 3 组 `Conv3×3(padding=1) + ReLU + MaxPool2×2`，通道 3→32→64→128；特征图 32→16→8→4；展平后 `Linear(2048→128) + ReLU + Dropout(0.5) + Linear(128→43)`。
3. **训练**：`CrossEntropyLoss` + `Adam(lr=1e-3)`，batch 64，10 个 epoch；每个 epoch 在测试集上算一次准确率。
4. **结果**：原始测试集准确率 **89.75%**（Loss 从 1.3890 降到 0.2008），并画出 Loss / Accuracy 曲线（保存在 `result.png`）。
5. **鲁棒性测试**：自己写了 `ChangeBrightness`、`AddGaussianNoise` 两个变换类，配合 `GaussianBlur`，构造了 4 个扰动测试集（低亮度 0.6 / 高亮度 1.3 / 模糊 σ=0.8 / 高斯噪声 std=0.03），逐一评估并算下降幅度，还抽了样本做可视化对比。
6. **改进实验**：设计了"数据增强 + 训练集均值方差标准化"的改进方案，并做了 A/B/C 三组消融对照。

### 6.2收获

- **为什么 `fc1` 的输入是 `128*4*4`**：三次池化把 32 变成 4，通道是第三次卷积输出的 128 → $128\times4\times4=2048$。这个数必须和前面结构严格对应，写错会在 `view()` 之后报维度不匹配。
- **为什么用 Dropout(0.5)**：全连接层参数最多、最容易过拟合，Dropout 在训练时随机丢弃一半神经元，迫使特征冗余化。
- **BatchNorm 与 Normalize 不是一回事**：`Normalize` 是对**输入数据**做固定尺度变换（用训练集统计量），BatchNorm 是**网络内部**对每层激活做动态归一化，两者可以同时用。
- **评价指标**：43 类任务里，Accuracy 够用，但如果某几类样本很少（GTSRB 类别不均衡），应补充**每类准确率/混淆矩阵/macro-F1**，否则会被大类掩盖。
